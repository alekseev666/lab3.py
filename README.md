# Трекер тренировок

Программа для учёта силовых тренировок. Есть две версии с общей базой данных:
- **десктоп** на Python и PySide6, внешний вид в стиле приложения «Заметки» на iPhone;
- **веб-версия** на FastAPI.

## Описание

В программе записываются тренировки: дата и подходы (упражнение, вес, повторения). Упражнения не вводятся вручную, а выбираются из базы: 20 упражнений, разбитых по группам мышц.

По прошлым тренировкам и стажу программа подсказывает, что делать на следующей тренировке: добавить повторение, прибавить вес или сделать разгрузку. Для любого упражнения можно поставить цель и следить за прогрессом к ней.

Ещё в программе есть:
- график активности — сколько упражнений сделано в каждый день;
- график результатов по каждому упражнению;
- журнал всех действий.

Данные хранятся в базе данных через SQLAlchemy: по умолчанию это файл SQLite `data/tracker.db`, в Docker — PostgreSQL.

## Запуск

Нужен Python 3.9 или новее (проверено на 3.14). Сначала установите библиотеки:

```bash
python -m pip install -r requirements.txt
```

### Десктоп

```bash
python main.py
```

При первом запуске программа попросит заполнить профиль.

### Веб-версия без Docker

```bash
python -m uvicorn web.app:app --reload
```

Откройте в браузере http://localhost:8000. Десктоп и веб-версия работают с одной базой `data/tracker.db`.

### Веб-версия с базой в Docker

Нужен установленный Docker Desktop. Команда запускает PostgreSQL и сайт:

```bash
docker compose up --build
```

Сайт откроется на http://localhost:8000, база доступна на порту 5432 (пользователь, пароль и имя базы — `tracker`). Данные базы хранятся в томе `db_data` и не пропадают после перезапуска.

Чтобы десктоп тоже работал с этой базой, поставьте драйвер и укажите адрес базы:

```bash
python -m pip install "psycopg[binary]"
```

```powershell
$env:DATABASE_URL = "postgresql+psycopg://tracker:tracker@localhost:5432/tracker"; python main.py
```

### Тесты

```bash
python -m pytest
```

Тесты проверяют логику прогрессии, работу с базой, веб-версию и окна десктопа. Каждый тест работает со своей временной базой, ваши данные не трогаются.

### Тренировка

1. Выберите упражнение: в десктопе кнопкой «Выберите упражнение» (там есть поиск), на сайте — в списке.
2. Вес и повторения подставятся по рекомендации, их можно поменять.
3. Нажмите «Добавить». В десктопе можно просто нажать Enter.

Подход удаляется кнопкой «Удалить упражнение» (в десктопе сначала выделите строку) или «Удалить» в строке на сайте. Там же можно изменить дату или удалить всю тренировку.

### Профиль и уровень

В профиле указывается дата, с которой вы занимаетесь. По ней считается стаж и уровень:

| Стаж | Уровень |
|---|---|
| меньше года | Новичок |
| от 1 до 3 лет | Средний |
| 3 года и больше | Опытный |

### Как считается рекомендация

- Сначала растут повторения до верхней границы диапазона (например, 6–10), потом прибавляется вес, а повторения снова начинаются с нижней границы.
- Новичок прибавляет вес сразу после верхней границы. Средний и опытный — после двух тренировок подряд, и шаг у них меньше.
- Перерыв больше 14 дней — повторить прошлый результат.
- Два раза подряд не дотянули до нижней границы — разгрузка, вес −10 %.
- В упражнениях с собственным весом растут повторения, в планке — секунды.

Стрелка ↑ — пора прибавить вес, ↓ — разгрузка.

### Мой прогресс и цели

На экране «Мой прогресс» собраны упражнения, которые уже есть в тренировках или для которых поставлена цель. «Показать все упражнения» показывает всю базу.

Клик по упражнению открывает его карточку: текущий результат, совет на следующую тренировку, цель, график и историю. Цель должна быть выше текущего результата.

### Где хранятся данные

| Что | Где |
|---|---|
| Профиль, тренировки, подходы, цели | база данных: таблицы `users`, `trainings`, `exercises`, `goals` |
| Журнал действий | `data/app.log` |
| База упражнений | `catalog/exercises.json` |

Если в папке `data/` остались файлы `user.json`, `trainings.json` и `goals.json` от старой версии, при первом запуске с пустой базой они переносятся в неё автоматически. Папка `data/` не попадает в git.

Адрес базы задаётся переменной окружения `DATABASE_URL`, папка с данными — `TRACKER_DATA`.
